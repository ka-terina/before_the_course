## Функционал

### class Product
Для этого класса прописаны основные свойства
*название*

*описание*

*цена*

*количество в наличии*

В классе реализована функция для выведения общей стоимости конкретного товара на складе
```
total_cost(self)
```

В классе реализована функция для вычисления полной стоимости всех товаров на складе 
```
__add__(self, other)
```

### class Category
Для этого класса прописаны основные свойства
*название*

*описание*

*список товаров категории*

Так же есть два атрибута класса

*количество категорий*

*количество товаров*

Реализована функция подсчета общего количества товаров в категории
```
get_total_quantity(self)
```

### class Smartphone класс-наследник от исходного класса Product

*производительность*

*модель*

*объем встроенной памяти*

*цвет*

### class LawnGrass класс-наследник от исходного класса Product
Помимо имеющихся свойств есть также 
*страна-производитель*

*срок прорастания*

*цвет*

### class BaseProduct базовый абстрактный класс, родительский для классов продуктов

### class MixinLog
При создании объекта распечатывает в консоль информацию о том, от какого класса и с какими параметрами был создан объект
```
Product('Продукт1', 'Описание продукта', 1200, 10)
```
